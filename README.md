# 오늘 뭐먹지? · 부산대 점심 뽑기

부산대학교 정문 주변 식당을 취향에 맞춰 고르는 원숭이 도트 슬롯 앱입니다.

- [앱 열기](https://sohyeon-kang.github.io/pnu-meal-slot/)
- 한식·양식·중식·일식·아시안·분식, 맛, 밥·면 조건으로 뽑기
- 맛집 도감 117곳, 점심 뽑기 115곳
- 식당별 메뉴·영업시간, 네이버 지도 링크
- 브라우저에 저장되는 찜·취향·최근 기록

## 실행과 확인

Node.js 설치 후 `npm start`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 추가 패키지는 필요 없습니다. `npm run check`와 `npm test`로 확인합니다.

## GitHub Pages 배포

저장소의 Settings → Pages에서 Deploy from a branch, main, /docs를 사용합니다. `docs/` 파일 수정 후 main에 push하면 갱신됩니다. `docs/.nojekyll`은 정적 파일을 그대로 게시하기 위한 파일입니다.

앱 코드는 `docs/app.js`, 식당 정보는 `docs/data.js`에 있습니다. 원숭이 SVG는 `node scripts/create-pixel-assets.mjs`로 다시 생성합니다.

## 데이터

최근 추가 확인일: 2026.10.08 (기존 자료 2026.10.05). 네이버 직접 확인 74곳과 리뷰 미확인 43곳을 구분하며 다른 플랫폼의 평점을 네이버 별점으로 표시하지 않습니다. 학생 이용 기록은 과거 자료도 포함하며 현재 인기 순위가 아닙니다. 영업시간과 실제 도보 경로는 방문 전에 확인해주세요.

2026.10.08 요청에서 기존 4곳은 중복 없이 유지하고, 점심 식사가 가능한 12곳을 추가했습니다. 17시 개점인 신짜글이닭발 부산대점과 16:30 개점인 늑간은 추가하지 않았습니다. [추가·제외 근거와 출처](research/lunch-additions-2026-10-08.json)에 메뉴·영업시간 자료와 사용자 지도 링크를 보존합니다. 서로 다른 영업시간 자료는 상세 화면에 확인 필요로 표시하며, 단축 링크 해석만으로 네이버 직접 확인 상태로 바꾸지 않습니다.

기존 점심 미확인 또는 저녁 영업 2곳은 도감에만 보관합니다. 개인정보·로그인·API 키가 필요 없는 정적 앱이며 찜과 기록은 각 브라우저에 저장됩니다. 다른 도메인에 저장된 찜은 자동으로 옮겨지지 않습니다.

Galmuri 글꼴의 라이선스는 [OFL.md](docs/assets/fonts/OFL.md)에 있습니다.
